# Armatra UI fonts

Static 400/500/600 instances of Inter, renamed Armatra UI to distinguish the
derivatives. Generated with fonttools 4.60.1; weight is pinned and all other axes
use source defaults. Copyright and full SIL Open Font License 1.1 are retained in
Inter-LICENSE.txt. Upstream: https://github.com/rsms/inter (Inter Project Authors).
No synthetic bold or runtime variable-font support is required.
